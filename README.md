# 相處指南｜約會觀察表

一款為手機設計的約會觀察 PWA，協助使用者在從初次認識、可能約會到交往階段中，逐步記錄綠旗、黃旗、紅旗、六題自我感受與重大安全警訊。

## 線上使用

啟用 GitHub Pages 後：

https://stephanieyou125.github.io/dating-checklist/

## 功能

- 可標記初次認識、朋友見面、可能約會、明確約會、曖昧或交往
- 第一次到第五次深入見面的分階段觀察重點
- 綠旗、黃旗與紅旗紀錄
- 六題自我評估與 12 分趨勢提示
- 四項進一步發展條件與下一步建議
- 關係恐懼辨識、五階段發展路徑、溝通句型與每週檢查
- 六大價值觀面向：忠誠、婚育、金錢、成長、生活地點與界線
- 重大紅旗獨立警示，不由總分抵銷
- 多位對象與歷次約會紀錄
- 手機本機儲存，不會把內容上傳到伺服器
- 支援離線開啟與加入 iPhone 主畫面
- 無廣告、無追蹤器、無外部套件

## 加入 iPhone 主畫面

1. 使用 Safari 開啟線上網址。
2. 點選「分享」。
3. 選擇「加入主畫面」。
4. 點選「新增」。

## 隱私說明

紀錄使用瀏覽器的 localStorage，僅保存在目前裝置與瀏覽器中。清除 Safari 網站資料、使用無痕瀏覽或更換裝置時，紀錄可能消失。請避免輸入真實姓名或其他敏感個資。

## 提醒

本工具用來幫助整理觀察，不是心理、醫療或法律診斷。若遇到暴力、威脅、強迫、跟蹤或其他安全風險，請優先離開危險情境並向可信任的人或當地緊急服務求助。
